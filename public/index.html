1 · D1 Connection

splint_masterdata / splint_prices / splint_transactions live in Cloudflare D1
Data is stored in Cloudflare D1, accessed through this site's own API and secured by Cloudflare Access (Google sign-in, restricted to approved accounts). Every change is saved to D1 immediately — uploads, master-data edits, all of it. There's no separate local state that would need to be saved manually anymore, and no token to manage in this browser.

2 · Upload Splint exports

Only these two buttons touch the original files from Splint
These uploads append new rows to the D1 tables — existing rows are never overwritten or deleted (price points are updated per asset/month, transactions are deduplicated by unique ID). Saved to D1 automatically right afterwards.
AInvestment Opportunities Export
Current positions with today's price. Added/updated as one price point per month in prices.csv (the latest upload for a given month only overwrites that month's value, never other months).
BActivities Export
Splint's complete transaction log. New transaction IDs are appended; existing ones are never duplicated or changed.
